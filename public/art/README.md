# Illustrazioni opzionali

Questa cartella è uno slot per la key art fatta a mano (per esempio esportata da Canva).
Il gioco funziona senza: se un file manca, resta lo sfondo generato proceduralmente.

| File | Dove appare | Formato consigliato |
|---|---|---|
| `title.jpg` | Sfondo della schermata titolo | 1600×2000, scuro, senza testo |
| `ending-seal.jpg` | Epilogo "Sigillo" | 1600×900, scuro, senza testo |
| `ending-succession.jpg` | Epilogo "Successione" | 1600×900, scuro, senza testo |
| `ending-restore.jpg` | Epilogo "Restituzione" | 1600×900, scuro, senza testo |

Le immagini vengono sovrapposte in `screen`/`soft-light` sopra il fondo nero, quindi
rendono meglio se sono già scure e ad alto contrasto, senza scritte (il testo lo mette la UI).
